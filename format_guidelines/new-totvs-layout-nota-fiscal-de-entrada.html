Integração Despachante ERP (Microsiga Protheus)

Esta documentação detalha a estrutura de integração de arquivos de texto plano ASCII (extensão .TXT) para importação direta via rotina "Integração" em Misceleana → Integração → Despachante no módulo SIGAEIC. O arquivo não contém delimitador de campos (largura fixa) e cada registro é encerrado com CRLF (Carriage Return + Line Feed, \r\n).

Registro Tipo "1" (Capa) 399 Caracteres (380 sem DUIMP)
Registro Tipo "2" (Item) 717 Caracteres (697 sem LI)
Codificação ASCII (Sem acentos/Símbolos)
Decimal Separator Obrigatório "." (Ponto)
⚠️

IMPORTANTE: Impacto da Reforma Tributária (Novos Tributos CBS e IBS)

O cálculo e gravação dos novos tributos federais CBS (Contribuição sobre Bens e Serviços) e IBS (Imposto sobre Bens e Serviços) foram incorporados nativamente ao módulo de recebimento do Protheus. Note que estes novos campos NÃO foram adicionados à estrutura do layout do arquivo TXT. Para que a tributação de CBS e IBS funcione corretamente durante a integração do arquivo:

  • Para processos DUIMP: As alíquotas e base de cálculo são herdadas dos dados da tabela de Itens de DUIMP (SWN).
  • Para processos DI: Os valores de CBS/IBS são calculados via regras vinculadas ao Cadastro de NCM associado ao item integrado.

Instruções de Formatação de Capa

Os campos devem ser concatenados sequencialmente sem nenhum espaço adicional entre eles. Campos numéricos com decimais devem conter o caractere ponto (ex: 00000000025.00). A data de entrega ou data de registro deve seguir o formato AAAAMMDD.

💡

Regra Geral de Cálculos Aduaneiros (Brasil)

Para evitar divergências tributárias na validação do SEFAZ ao integrar o arquivo TXT, certifique-se de que os cálculos de base de imposto sejam submetidos à ordem cascata brasileira descrita abaixo.

1. Valor Aduaneiro (Base Fundamental)

Representa o custo total da mercadoria até chegar ao porto/aeroporto de entrada nacional. Serve como base de cálculo padrão para o imposto II.

Valor Aduaneiro Valor Aduaneiro = FOB + Frete Internacional + Seguro Internacional

2. Imposto de Importação (II) e IPI

O IPI incide sobre a soma do valor aduaneiro e do valor apurado do próprio Imposto de Importação (II).

Fórmulas II & IPI Base II = Valor Aduaneiro
Valor II = Base II × Alíquota II (%)

Base IPI = Valor Aduaneiro + Valor II
Valor IPI = Base IPI × Alíquota IPI (%)

3. PIS e COFINS

Geralmente calculados diretamente sobre o valor aduaneiro bruto (método simplificado adotado por padrão no importador).

Fórmulas PIS/COFINS Base PIS = Valor Aduaneiro
Valor PIS = Base PIS × Alíquota PIS (%)

Base COFINS = Valor Aduaneiro
Valor COFINS = Base COFINS × Alíquota COFINS (%)

4. ICMS "Por Dentro" (Cálculo em Cascata)

O ICMS possui base de cálculo própria que engloba todos os tributos federais devidos (II, IPI, PIS, COFINS), mais despesas aduaneiras (taxa Siscomex, etc.), dividida pelo fator complementar da própria alíquota interna da UF.

ICMS CASCATA Base Bruta = Valor Aduaneiro + Valor II + Valor IPI + Valor PIS + Valor COFINS + Despesas Aduaneiras
Base Final ICMS = Base Bruta / (1 - Alíquota ICMS %)
Valor ICMS a Recolher = Base Final ICMS × Alíquota ICMS (%)
📝

Novas Bases de CBS e IBS (Pós Reforma)

Caso aplique-se regras de tributos da Reforma, a base agregada do CBS e IBS será composta por:
Valor Aduaneiro + Despesas Base de Imposto - Deduções + Despesas de ICMS + II + PIS + COFINS (excluindo IPI e o próprio ICMS).

💡 Dicas Rápidas de Diagnóstico:
  • Se sua linha tiver menos ou mais caracteres do que o esperado (399 para Capa, 717 para Item), o Protheus irá rejeitar o registro ou interpretar os campos de forma desalinhada.
  • Certifique-se de que não haja acentos ou caracteres especiais em textos como a Descrição do Produto.
  • Verifique se as datas não contêm caracteres de barra "/" ou traço "-".
